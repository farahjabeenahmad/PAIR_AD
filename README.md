# Alzheimer OCT Dataset Audit & Classification

This repository contains initial dataset exploration, structural auditing, and model training pipelines for the Dryad Alzheimer's Optical Coherence Tomography (OCT) dataset.

## Repository Layout
- `notebooks/01_dataset_audit.ipynb`: Scans raw files, categorizes subject folders (AD, CO, YA, AQ), and verifies volume metadata.
- `data/`: Folder designated for dataset storage (not included in Git repository due to size).
